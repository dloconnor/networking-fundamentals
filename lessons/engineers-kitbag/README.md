# Quick Lesson — Engineers kit bag

Every engineers kit bag will be different but if your intention is to work with physical networks here are some basic useful tools you'll need:

## Physical Tools
- Laptop
- Console cable - requirements may vary dependant on the vendor equipment you'll be working on but the typical console cable has a USB to RJ45 connector:
