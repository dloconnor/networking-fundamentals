# Networking Fundamentals for the AI Generation

Everyone wants to learn AI.  Everyone wants to get into cybersecurity, cloud, DevOps, software engineering, automation, Kubernetes, penetration testing, or whatever the next big technology happens to be.
And that’s great. But underneath almost all of it is something much less fashionable:

**Networking.**

## Learn the basics first.

The intention of this repository is simple - focused, hands-on networking fundamental labs that every engineer should understand.

No prior networking experience required.
